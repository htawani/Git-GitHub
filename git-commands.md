
**### Initialize local file system for versions control system ###**

1/ Change directory  --> 
$ **cd absolute-dir-path**

2/ Initialize git VCS and empty repository  --> 
$ **git init**

3/ To check repository status  --> 
$ **git status**

4/ To make file ready from untracked to staged  --> 
$ **git add filename**

5/ To undo/remove file from staged to untracked  --> 
$ **git rm --cached filename**
